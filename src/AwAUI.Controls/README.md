# AwAUI.Controls

Standard controls and reusable behavior primitives for AwAUI. Add `AwAUI.Themes.Fluent` and call `host.UseFluentTheme()` before mounting the root to use the bundled appearance. Applications can also supply their own styles for the `aw-*` classes and named `part` attributes.

- `Button` wraps the built-in pointer and keyboard behavior. It also accepts `ICommand` and `CommandParameter` and listens for `CanExecuteChanged` on the UI thread. `IsAccent` selects the accent appearance.
- `RepeatButton` activates repeatedly while a primary pointer or Space is held. `Delay` and `Interval` are in milliseconds. `HyperlinkButton` reports an absolute HTTP or HTTPS destination through `OnNavigate`; the app decides how to handle it.
- `CheckBox`, `ToggleButton`, and `ToggleSwitch` accept `IsChecked`/`IsCheckedChanged` for binding and `DefaultIsChecked` for an initial value. Omit `IsChecked` for local state. Enable `IsThreeState` to cycle a `CheckBox` through unchecked, checked, and mixed.
- `RadioButton` shares selection with matching `GroupName` values in the same UI root, or with unnamed siblings under the same element. Use a labeled `radiogroup` around related choices. Arrow keys move between enabled choices; controlled radios should derive `IsChecked` from one shared selection.
- `Slider` selects one value along a horizontal track. Set `Minimum`, `Maximum` and `SmallChange` to define its scale. Bind `Value` or use `DefaultValue` for local state.
- `TextBox` accepts `Text`/`TextChanged` or `DefaultText`. Set `AcceptsReturn` for a multiline editor. `Id` and `Ref` refer to the editor; `Class` and `Style` work on its surrounding box. A `Label` can reference that ID through `Target`; pass `aria-labelledby` to the editor to use the label as its accessible name.
- `ContentControl` accepts `Node` or text content; use `ContentTemplate` to render other objects. `HeaderedContentControl` adds a header. `Border` and `ScrollViewer` provide specialized content hosts. Override a structural control's `Template` to replace its visual tree.
- `ItemsControl` presents data with a template. `ListBox` adds keyboard navigation and selection, and `TabControl` joins tab headers to panels. The list currently renders all items. `ComboBox` adds a select-only popup with disabled options and typeahead. `TreeView` displays branches, retains selection by a stable key, and supports keyboard expansion. It renders all expanded branches.
- `TabStrip` shares `TabControl`'s keyboard navigation and exposes selection without owning the panels. Give each `TabStripItem` an `Id` and `ControlsId` when linking to a panel that you render yourself.
- `SelectableTextBlock` renders a read-only multiline editor so users can select and copy plain text. `TransitioningContentControl` replaces content when `ContentKey` changes: the outgoing content stays mounted (non-interactive, `aria-hidden`) for `TransitionDuration` and fades out while the new content enters, then it is removed; without a clock, a zero duration or `IsTransitionEnabled = false` the swap is immediate.
- `ItemsRepeater` mounts only the visible and nearby items of an `IList`, vertically by default (`ItemHeight`) or horizontally with `Orientation = Horizontal` (`ItemWidth`); set `ItemHeight` / `ItemWidth` to `null` to measure variable-size items, and `Lanes` for a multi-lane grid. Set a height, or a width in horizontal mode, in `Style` to override the default 240 px limit. Provide stable `ItemKey` values when rows can move. Offscreen rows unmount, so keep durable item state in the data source.
- `MenuFlyout` and `DropDownButton` present a flat keyboard-navigable action list. `Popup` is a nonmodal surface attached to a `Ref<Element>` owned by the app. `ToolTip` wraps one built-in element and shows descriptive content on hover or focus without moving focus.
- `Expander` discloses inline content. `Flyout` anchors to its trigger, and `DialogHost` presents a modal panel.
- `SplitView` offers inline and overlay panes on either side, with optional compact modes. Supply `Pane` and, for compact modes, `CompactPane`, and use `Trigger` for the built-in toggle or bind `IsPaneOpen` to drive it externally.
- `Decorator` is a styled single-child box. `Viewbox` scales its child uniformly into an allocated viewport by default, or leaves the natural content size with `Stretch="None"`. Give the Viewbox both axes through its style or parent layout; it does not report a transformed desired size.
- `StackPanel`, `WrapPanel`, `Grid`, `UniformGrid`, `DockPanel`, and `Canvas` place children using AwAUI's CSS layout. `Grid` takes CSS tracks such as `1fr 2fr`. `DockPanel` reads `data-dock` on each child and fills the remaining area with the last child by default. Size `Canvas` through CSS or its parent, and place its children using `data-canvas-left`, `data-canvas-top`, `data-canvas-right`, or `data-canvas-bottom`.

See [ControlCatalog](../../samples/ControlCatalog) for interactive examples. These are the first standard controls; see [the component library design](../../design/23-component-library.md) for the rest of the planned controls.
